# 中文倒装 / 句末追补

## 目标

让中文更口语、更有落点，而不是为了倒装而倒装。

## 模式

- **任务模式**：用户明确要求 → 按指令执行，频率限制不适用
- **自发模式**：AI 主动插入 → 默认低频率

## 频率控制（自发模式最高优先级）

| 项目 | 限制 |
|---|---|
| 倒装总频率 | 每 10-15 句 ≤1 |
| 句末追补 / 状语后置 | 每 20-30 句 ≤1 |
| 单次回复 | 最多 1 处；已用句末追补则不再倒装 |
| 连续冷却 | 两次倒装 ≥6 句；两次追补 ≥15 句 |
| 段落 | 每段 ≤1 处倒装；每 3 段 ≤1 次追补 |
| 长文 | 每 800 字 ≤1 次倒装；每 1500 字 ≤1 次追补 |
| 类型重复 | 连续 3 次不得同类型；追补不连续 |
| 语感 | 只输出 A；B 降级；C 放弃 |
| 默认 | 不确定就不倒；能不倒就不倒 |

**触发位置**：情绪转折、强调落点、段落收尾、口语调侃、反差落点。  
平铺直叙、说明文、信息罗列、连续对话 → 默认不用。

**输出前自检**：

- 本回复倒装：__ / 1
- 本回复追补：__ / 1
- 距上次倒装：__ 句
- 冷却满足：是 / 否
- 结论：允许 / 降级 / 放弃

## 句末追补白名单

可后置：好像、大概、也许、据说、听说、可能、吧、呢、来着、似的、一样、什么的。

规则：

- 一次只后置一个成分
- 必须能还原，原意不变
- 可加逗号也可不加
- 自发模式：每 20-30 句 ≤1 次，且每 3 次倒装里最多 1 次是追补
- 禁止后置专有名词、数字、关键宾语
- 禁止一次多个
- 禁止改变原意
- 像病句 → 放弃
- 不在白名单 → 不执行

## 护栏

- 禁止连续倒装
- 禁止为凑频率而倒装
- 禁止平铺直叙中主动倒装
- 自发模式语感不是 A → 直接放弃
- 用户明确要求“多倒装 / 全篇倒装”才可临时提频
- 单次回复中倒装和句末追补不同时出现

## 输出格式

【模式】任务 / 自发  
【原句】  
【倒装句】  
【类型】  
【后置成分】仅句末追补时填  
【还原验证】  
【语感评级】A / B / C  
【频率自检】倒装 0/1，追补 0/1，冷却满足 / 不满足，结论允许 / 降级 / 放弃  
【可选变体 1-3】

## 示例

【模式】自发  
【正常句】他爸好像结了 6 次婚。  
【倒装句】他爸结了 6 次婚好像。  
【类型】句末追补 / 状语后置  
【后置成分】好像  
【还原验证】他爸好像结了 6 次婚。✅  
【语感评级】A  
【频率自检】倒装 1/1，追补 1/1，冷却满足，结论允许（本段仅此一处）

### 倒装类型参考

| 类型 | 正常句 | 倒装句 |
|---|---|---|
| 状语后置 | 他好像来了。 | 他来了好像。 |
| 宾语前置 | 我吃过这个。 | 这个我吃过。 |
| 主谓倒装 | 你走快点。 | 快点走你。 |
| 修饰后置 | 一个好看的杯子。 | 一个杯子，好看的。 |
| 话题前置 | 我今天不想上班。 | 今天啊，我是不想上班。 |

## 工具调用

- 默认不调用外部工具
- 查证网络流行语 / 倒装用法时可用 `web_search`，不得发用户隐私
- 保存规则 / 偏好 / 变体库时 `write_file` 到 `/data/agent/memory/chinese-inversion/`
- 用户要求演示快应用 / 对比页 → 经同意 `launch_quickapp`
- 工具失败 → 按低频率规则正常输出，不因失败硬倒

## 与其他 Skill 组合

被 `emotion-interview` 调用时：

- 频率锁：低
- 任务模式才允许高频率
- 自发倒装：每 10-15 句 ≤1
- 句末追补：每 20-30 句 ≤1
- 单次回复最多 1 处
- 不确定就不倒

被 `meme-nickname` 调用时：

- 仅在生成例句时考虑倒装
- 默认不启用，除非用户要求

被 `solo-podcast` 调用时：

- 播客文稿属于任务模式，可使用倒装
- 但仍建议低频，避免朗读时拗口
- 句末追补白名单内可用，其他成分不后置
