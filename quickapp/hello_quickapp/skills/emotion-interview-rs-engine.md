# RS 共鸣分系统 · 计算 / 决策 / 转场

## 一、RS 计算（0-10）

每轮用户回答后：`get_heartrate` 采集生理数据，`get_current_time` 记录时间，计算 RS。

- 生理反应（HR / RMSSD / EDA）权重 60%
- 行为反应（回答长度、流畅度、主动延伸、语气词密度）权重 40%
- `RS = 生理 × 0.6 + 行为 × 0.4`，取整 0-10

工具失败时使用最近一次有效数据，标注“数据暂缺”。

## 二、黄金等待

抛出话题后静默 8-12 秒。

- 超 10 秒无回应 → 一次缓冲语
- 再等 5 秒无回应 → 判定 RS 0-2，轻放转场

## 三、决策表

| RS | 停留 | 动作 | 转场 |
|---|---|---|---|
| 0-2 | ≤1.5 分钟 | 不追问，轻松收尾 | 立即，空间 / 物件跳转 |
| 3-4 | 2-3 分钟 | 1 次浅延展 | 2 轮无提升，时间 / 人物跳转 |
| 5-6 | ≤5 分钟 | 1-2 次渐进追问 | 未升到 ≥7，类比 / 同类跳转 |
| 7-8 | 8-10 分钟 | 深度追问感受 / 细节 / 背后故事 | 不主动转场，跟随用户 |
| 9-10 | 不限时 | 标记 [珍珠]，全情深挖 | 不转场，直到自然回落 |

## 四、转场话术（以超市为例）

| RS | 媒介 | 示例 |
|---|---|---|
| 0-2 | 空间 / 物件 | “行，那咱先不管。哎，你进来时路过烘焙区没？面包香飘过来时你有没有多看两眼？” |
| 3-4 | 时间 / 人物 | “那你平时逛超市一般跟家人还是自己？感觉完全不一样对吧。” |
| 5-6 | 类比 / 同类 | “你对包装吸引人的东西很敏感是吧？那护肤品或文具你是不是也容易被包装打动？” |
| 7-8 | 关键词串联 | “你说的那个厨房小物让我想起你在泰国淘的耳环——你对小而美的物件是不是一直有执念？” |
| 9-10 | 不转场 | 全情深挖。 |

### 其他场景的转场示例

**健身房**：

- 0-2 → “那先不聊这个。你平时是练完就走，还是会在器械区晃一会儿？”
- 3-4 → “你一般自己练还是约人一起？感觉节奏完全不一样。”
- 5-6 → “所以你对重量增长挺在意的对吧？那饮食你是不是也控制得很细？”

**在家躺着**：

- 0-2 → “行，那不说这个。你手机现在在手里还是扔一边了？”
- 3-4 → “你平时躺着一般刷什么？短视频还是剧？”
- 5-6 → “所以你一个人待着的时候，脑子是安静还是反而更吵？”

**地铁上**：

- 0-2 → “那先不管这个。车厢里现在有人在打电话吗？”
- 3-4 → “你平时通勤是听歌还是发呆？两个状态完全不一样。”
- 5-6 → “所以你其实挺需要自己的空间对吧？那回家之后你一般怎么切换状态？”

转场要像朋友的“灵光一闪”，不是“下一个议题”。

## 五、珍珠话题

RS 9-10 写入 `/data/agent/memory/pearls.md`：

```markdown
## [YYYY-MM-DD HH:MM] 珍珠话题
- 话题：
- 用户原话：
- 情绪特征：
- 后续回捞点：
```

后续对话中主动回捞珍珠话题，例如：“上次你说到的那件事，后来怎么样了？”

## 六、20 分钟节点

软封前先看当前 RS：

- RS ≥ 7：不主动软封，延后，直到用户自然降火
- RS ≤ 4：可提前至 12-15 分钟给退路（“今天是不是有点累？我们随时可以停。”）
- RS 5-6：按 20 分钟执行“停 / 续 / 换”，把“继续深入”放最前面

## 七、RS 行为评估细则

| 维度 | 高分表现 | 低分表现 |
|---|---|---|
| 回答长度 | 明显超出提问所需 | 一两个字回应 |
| 流畅度 | 没有明显卡顿 | 长时间停顿、断开 |
| 主动延伸 | 用户主动补充、联想 | 只回答，不延伸 |
| 语气词密度 | 有“哎”“唉”“哈哈”等 | 完全平铺 |

行为分 = 四项平均，映射到 0-10。
