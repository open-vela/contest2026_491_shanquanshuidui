# logs/hezorrrr/ 补充说明

本队开发期使用的 AI 编码工具为 **TRAE AI Coding IDE**（中后期主力）与 ChatGPT / Claude 等通用 LLM（初期）。由于《AI Coding 日志归集与提交手册》Q9 明确官方采集器（contest-log-collector）仅支持 Claude Code / AIoT-IDE / OpenCode / Codex，TRAE 会话无法被自动采集为 JSONL，故本目录以如下方式提交 AI Coding 证据：

| 材料 | 说明 |
|------|------|
| `logs/AI_Coding_Log.md` | AI Coding 全过程说明文档（工具、模块、参与度、问题排查） |
| `logs/hezorrrr/2026-09-17/trae__aiot-ide-ui-demo-and-ai-chat.md` | TRAE 会话导出（趋势图渲染修复、提交流程梳理、AI_Coding_Log.md 生成） |
| TRAE 会话分享链接 | https://share.traecontent.cn/share/FWOLQ-FLBVS_3H?enter_from=pc |

本目录未包含官方采集器生成的 `.jsonl` 文件——开发期未在 openvela 工作区内使用受支持的四款工具进行会话，不存在对应采集数据。以上材料为诚实提交的真实开发记录。
